# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

- `npm run dev` — Vite dev server on port 3000
- `npm run build` — production build (Vite + Nitro SSR)
- `npm run preview` — preview built app
- `npm test` — Vitest run (single-shot, non-watch)
- Single test: `npx vitest run path/to/file.test.ts` or `npx vitest -t "test name"`
- `npm run lint` — ESLint via `@tanstack/eslint-config`
- `npm run typecheck` — `tsc --noEmit`
- `npm run format` — Prettier write `**/*.{ts,tsx,js,jsx}`

Add shadcn component: `npx shadcn@latest add <name>` → lands in `src/components/ui/`.

## Architecture

TanStack Start app (SSR via Nitro) + React 19 + TypeScript + Tailwind v4 + shadcn/ui.

- **Routing**: file-based via `@tanstack/react-router`. Routes live in `src/routes/`. `routeTree.gen.ts` is auto-generated by `@tanstack/router-plugin` (Vite) — do not edit by hand. Root shell in `src/routes/__root.tsx` (HTML document, head meta, devtools). Router factory in `src/router.tsx` (`defaultPreload: "intent"`).
- **SSR**: `tanstackStart()` + `nitro()` Vite plugins handle server entry. No manual server file.
- **Styling**: Tailwind v4 via `@tailwindcss/vite`. Single stylesheet `src/styles.css` imported as `?url` in root route. shadcn config: `style: base-nova`, `baseColor: neutral`, CSS variables, Lucide icons.
- **Path alias**: `@/*` → `src/*` (tsconfig + `vite-tsconfig-paths`). shadcn aliases: `@/components`, `@/components/ui`, `@/lib`, `@/lib/utils`, `@/hooks`.
- **`cn()` helper**: `src/lib/utils.ts` — `twMerge(clsx(...))`. Use for all conditional class composition.

## Conventions

- Prettier: no semis, double quotes, 2-space, trailing-comma `es5`, printWidth 80. `tailwindFunctions: ["cn", "cva"]` so class strings inside those calls get sorted.
- TS strict + `noUnusedLocals` + `noUnusedParameters` + `verbatimModuleSyntax` (use `import type` for type-only imports).
- React 19 — no `forwardRef` needed; `ref` is a regular prop.
